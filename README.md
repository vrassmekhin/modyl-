# 🧠 МодульТренер — подготовка к модульному экзамену

Современное веб-приложение для **быстрого и глубокого запоминания** материала к комплексному
модульному экзамену по трём дисциплинам:

- 🧠 **Психология** (30 билетов) — на основе лекций В. В. Петухова и открытых источников
- 🌍 **Социология** (40 билетов) — на основе учебников С. С. Фролова и Э. Гидденса
- 📈 **Экономическая теория** (54 билета) — на основе учебника М. Н. Чепурина и Е. А. Киселёвой

Всего **124 билета** с полным разбором, карточками, тестами и мнемотехникой.

> Приложение ориентировано не на чтение, а на **активное вспоминание, интервальное повторение
> и успешную сдачу экзамена**. Окно подготовки настроено на три дня: 14, 15 и 16 июня.

## ✨ Возможности

| Раздел | Что внутри |
|---|---|
| **Главная** | Общий процент готовности, изученные / в работе / проблемные билеты, ближайшие повторения, ежедневная цель |
| **Билеты** | Полный ответ, краткий конспект, схема-конспект, интеллект-карта, тезисы, определения, термины, даты, учёные, примеры, экзаменационные вопросы |
| **Изучение → Active Recall** | После «Я изучил материал» ответ скрывается; вы воспроизводите его сами, затем оцениваете себя (4 градации) |
| **Интервальное повторение** | Алгоритм SRS, сжатый под 3-дневное окно: уровень знания, момент следующего повторения, история |
| **Карточки** | 6 типов карточек (термин↔определение, учёный↔теория, вопрос→ответ, пропущенное слово), листание как в Anki |
| **Тесты** | Авто-генерация: один/несколько ответов, сопоставление, последовательность, открытые вопросы + балл, ошибки, пояснения |
| **Экзамен** | Случайный билет, устный/письменный ответ, эталон, самооценка, сохранение результатов |
| **Мнемотехника** | Ассоциации, аббревиатуры, истории, образы, методы для каждого билета |
| **Аналитика** | Готовность, рейтинг предметов, слабые/сильные темы, прогноз к экзамену, часы подготовки, графики успеваемости и повторений |
| **Геймификация** | Уровни, XP, достижения, серии дней, медали, рейтинг предметов |
| **Поиск** | Глобальный поиск по терминам, определениям, фамилиям, тезисам и билетам |

Карточки и тесты **генерируются автоматически** из структурированных данных каждого билета.

## 🎨 Дизайн

- Тёмно-синяя основа + бирюзовый акцент; зелёный/оранжевый/красный для прогресса
- Светлая и тёмная темы (переключатель в шапке)
- Адаптивный минималистичный интерфейс (десктоп и мобайл)

## 🚀 Запуск

```bash
npm install      # установка зависимостей
npm run dev      # режим разработки (http://localhost:5173)
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр сборки
```

Весь прогресс сохраняется локально в браузере (`localStorage`) — бэкенд не требуется.
